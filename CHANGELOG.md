# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0](https://github.com/hamsitech/webherd/releases/tag/v0.1.0) (2026-07-27)

### Added

- Project registration with Herd-style `.test` hostnames for JS dev servers
- Dashboard at `http://webherd.test`, running as a LaunchAgent: start/stop, http/https toggle via the Herd CA, log viewer, rename, port change, unregister
- Android emulator DNS companion resolving `*.test` to `10.0.2.2` (boot the emulator with `-dns-server 127.0.0.2`)
- App bundle stub so background items show webherd's name and icon in System Settings
